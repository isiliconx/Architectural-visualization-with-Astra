# STILLWATER HOUSE

A cinematic, fully procedural Blender residence designed around limestone, smoked oak, bronze, low-iron glass and a reflective Mediterranean garden.

## Production

The editable scene, deterministic generator and verified renders are in production. Final backup will include all source needed to rebuild the scene. No external meshes or image textures are required.

## Design

- A long, low living pavilion with a textured stone bedroom wing.
- Bespoke upholstered furniture, ash joinery, ceramic vessels, dining chairs and a functional kitchen.
- Olive trees, lavender, meadow grasses, stepping stones and a reflecting pool.
- Warm late-afternoon daylight with restrained architectural lighting.

Created in Blender 4.5.3 LTS. Concept visualization only, not construction documentation.
